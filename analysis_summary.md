# Analysis Summary

## Q1 – Dataset
Stack Overflow Developer Survey 2024 was selected because it is a large public dataset relevant to technology adoption, developer skills and AI trends.

## Q2 – Business Questions
- Which programming languages are most widely used?
- Which technologies do developers want to use in the future?
- What is the level of AI adoption?
- Does technology preference vary by experience?
- Which skills should companies prioritize for hiring and training?

## Q3 – Data Preparation
- Removed duplicate records
- Standardized column names
- Identified missing values
- Processed multi-select technology fields
- Created experience groups
- Prepared AI adoption fields

## Q4 – Key Insights
- JavaScript has high adoption.
- PostgreSQL has strong database adoption.
- Visual Studio Code is highly popular.
- AI tools are becoming important in developer workflows.
- Current adoption and future technology interest are not always the same.

## Q5 – Unexpected Result
Current technology adoption does not always match future technology preference. Companies should consider both current usage and future demand.

## Q6 – Limitations
- Survey responses are self-reported.
- Respondents may not represent the entire developer population.
- Multi-select questions require careful processing.
- Observational data cannot establish causation.

## Q7 – Recommendations
1. Build responsible AI-assisted development capability.
2. Prioritize high-demand technology skills in hiring.
3. Create continuous technology upskilling programs.
4. Monitor emerging technologies regularly.

## Q10 – How AI Was Used
ChatGPT was used to understand assessment requirements, structure business questions, plan the analysis, organize findings and prepare the presentation. Key dataset facts and methodology were verified against the official Stack Overflow source.
